Meal Tracker

\- An app to save and plan when to eat meals.

This app strives to make saving recipe videos from social media more practical and functions as a generic information saving app that you can use to save a meal and schedule it.  



Features

* Home/suggestions page - View #mealprep videos on YouTube straight from the app.

* Save meals - Meals you save don't go anywhere, they're saved and will appear next time you open the app.

* Plan meals - Use the calendar page to select a date and add your saved meals to it.
 
* Calorie and cost accumulation - On a selected date, total cost and calories for meals will be calculated.



* Edit existing meals - You can edit existing meals to correct or edit information

* Delete meals - Ability to remove meals if you're disgusted or change your mind.

* Add image to meal - When creating or editing a meal, you can take a picture or upload an image of the meal.

* Export/import - As there's no backend, you can back up your own data and use it to upload your meals to other devices.

* Description capture - When saving a meal from a YouTube, Instagram, or TikTok, a button will appear which will copy the description of the video, which usually contains the ingredients and instructions, and paste it into the text box for convenience.

* Dark and light mode - Different themes



Tools

* Bootstrap - Used for overall design and displaying meal information through the use of cards and modals

* JS, HTML - Functionality and structure

* CSS - Designing specific elements that bootstrap couldn't

* Localforage - Vastly increased storage limits to replace localstorage (5mb limit). Enables saving multiple images.

* Microlink API - Fetches meta data from Instagram and TikTok videos. The app only uses the description field from the capture.

* Youtube API - Fetches the description from YouTube videos. 

* JS Fullcalendar - Responsible for the calendar functionality (month format, back/forward arrows, dateclick function)

* Curator.io - Displays the YouTube #mealprep feed from my free curator.io account. Can be customized on https://app.curator.io/style/feed-layout
